# 10章　Skill を自分用に直す

## はじめに

前の章の最後に、こんな疑問が残りました。

「会社の Skill を、自分用に直してもいいの？　直したら、みんなの Skill まで変わってしまわない？」

共有フォルダにある会社の手順書は、自分の都合で書き換えたりしませんよね。直したいところがあれば、担当の人に相談します。

**会社の Skill も同じです。** 会社の Skill を直せるのは、会社が決めた人（管理者や「Skill を直せる人」）だけです。あなたが会社の Skill をうっかり書き換えて、みんなの AI の動きが変わってしまう、ということは起きないようになっています。

1日目は、9章の「見る・使う」ができれば十分です。この章は、「自分に合わせて試したくなったら、こうできる」という紹介です。

---

> **自分用の Skill を作って試す**
>
> 会社の Skill をもとに、**あなたの PC だけで使う自分用の Skill** を作って、試すことができます。
>
> 1. 自分の部署のタブ（たとえば「営業部」）で、左の欄の［Skill］を開きます。
> 2. カードの並びの下にある［他からコピー］を押します。
> 3. 「他の部署から Skill をコピー」の画面で、もとにしたい Skill を選びます。
> 4. 新しい Skill の名前と、フォルダの名前（英語の小文字・数字・「-」「_」だけ）を入れて、［コピーして作成］を押します。
> 5. できた Skill の［設定］を押し、「SKILL.md」を開いて、自分のやり方に書き換えます。「AIへの相談」で、AI に直してもらうこともできます。
>
> その部署の Skill を直せる人でなければ、コピーした Skill は**あなたの PC の中だけ**に置かれます。一覧では「非公開」のまとまりに入り、［設定］を開くと「非公開 — あなただけ」と出ます。同期しても、ほかの人には届きません。
>
> 使い方は会社の Skill と同じです。入力欄で「/」を打つと、一覧に出てきます。
>
> **良くなったら、管理者に相談しましょう。** 「この書き方のほうがうまくいきました」と伝えれば、会社の Skill に取り入れてもらえるかもしれません。［公開する］というボタンもありますが、Skill を直せる人でなければ、押しても断られます。

> **注意：あなたが「Skill を直せる人」のとき**
>
> あなたが管理者や部署の管理役、「Skill を直せる人」のときは、コピーした Skill は次の同期で部署のみんなに届きます。試すだけのつもりなら、先に管理者と相談してから作りましょう。

## 自分用に直す前のチェック

| 確かめること | はい／いいえ |
|---|---|
| 会社の Skill そのものではなく、コピーした自分用の Skill を直していますか？ | |
| ［設定］を開くと「非公開 — あなただけ」と出ていますか？ | |
| 直した Skill で、AI に1回頼んで、できたものを自分の目で確かめましたか？ | |
| 良くなったところを、管理者に伝えましたか？ | |

---

ここまでで、1日目の AI の使い方はおしまいです。ファイルを開いて直し、AI に頼み、Skill を使う。どれも、まずはあなたの PC の中で起きることでした。

では、あなたや AI が作ったファイルを、営業部のみんなに届けるには、どうすればいいのでしょうか？　ここからは「困ったとき・もっと知る」として、同期とフォルダのことを見ていきます。
