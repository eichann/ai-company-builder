# 管理者・FDE の手引き

## この節でできること

- 管理画面の開き方と、左のメニューの見方が分かります
- オーナー・管理者・部署の管理役などの役割で、それぞれ何ができるかが分かります
- この手引きをどの順で読めばよいかが分かります

---

## この手引きを読む人

ACB を入れた会社で、人を招き、部署と権限を決め、困ったときに止める人のための手引きです。

- **オーナー・管理者**：会社を動かす人。エンジニアでなくても読めるように書いています。
- **FDE**：会社の立ち上げと自動化を手伝うエンジニア。鍵・業務プラグイン・定期の仕事・ブラウザ操作などを受け持ちます。

小さな会社では、管理者と FDE が同じ人のことも多いので、1冊にまとめました。**見出しの最後に【FDE】が付いている節は、FDE がやることが多い所です。** 管理者は、その節の頭に書いた「管理者が知っておくこと」だけ読めば大丈夫です。

社員が使う画面のことは、社員向けの「使い方」（社員の取説）に書いてあります。社員の画面に何が出るかは、そちらを先にざっと見ておくと読みやすくなります。

この手引きでは、FDE の **田中さん** が **検証A社** の立ち上げを手伝う流れで話を進めます。社長（オーナー）は **高橋さん**、総務部で管理者をする **佐藤さん**、営業部の社員の **山田さん** も出てきます。どれも架空の会社と人です。

---

## 管理画面を開く

Google Workspace に管理コンソールがあるように、ACB にも管理画面があります。アプリの中ではなく、**ブラウザで開きます。**

1. 会社の ACB のアドレス（アプリと同じサーバーのアドレス）をブラウザで開きます。
2. 「ログイン」の画面で、アプリと同じ「メールアドレス」と「パスワード」を入れて［ログイン］を押します。

［写真：/login — ログイン画面（① メールアドレス ② パスワード）］

ログインすると、前に開いた会社（はじめてなら一覧の最初の会社）がそのまま開きます。いくつかの会社に入っている人は、左のメニューのいちばん上の「会社」から切り替えます。

## 左のメニュー

左のメニューには、上から次のものが並びます。役割によって、出るものが変わります。

| メニュー | 出る人 |
|---|---|
| ホーム | 全員 |
| メンバー | オーナー・管理者 |
| 見える人のまとまり | オーナー・管理者 |
| 部署 | 全員 |
| フォルダ | オーナー・管理者・部署の管理役（全社フォルダを使う会社だけ） |
| 会社の Skill | オーナー・管理者・部署の管理役・Skill を直せる人（全社フォルダを使わない会社だけ） |
| つなぎ先 | オーナー・管理者 |
| 定期の仕事 | オーナー・管理者 |
| 詳しい設定（いちばん下） | オーナー・管理者 |

オーナーと管理者には、どのページの上にも赤い［AI を止める］が出ます（14節）。

［写真：/companies/:id — 左のメニュー全体（オーナーで）。① ふだん使う8つ ②「詳しい設定」③［AI を止める］］

---

## 役割の早見表

| 役割 | できること |
|---|---|
| オーナー | すべての操作。**役割の変更（管理者の任命・解除）はオーナーだけ** |
| 管理者 | 役割の変更のほかは、すべての操作 |
| 部署の管理役 | 自分の部署の非公開フォルダ・AI への指示ファイル・Skill を扱い、所属する人を直せる。ホームでは自分の部署の人の状態だけ見える |
| Skill を直せる人 | 会社の Skill を直せる（ほかの人は Skill を書き換えられない） |
| 運用担当者 | ACB のサーバーを動かしている人。会社を作る・Google の会社の登録・業務プラグインを用意する、など（15節） |

部署の管理役と Skill を直せる人は、役割ではなく、メンバーに付ける「任せごと」です。運用担当者は会社のメンバーではなく、サーバーの側の人です。

考え方はひとつです。**社員は楽に。ややこしいことは、管理者と FDE が引き受けます。**

---

## 社員の取説を開く

社員の取説は、サーバーのアドレスの `/manual/` で開けます。ログインした人だけが読めます。ログインしていないときは管理画面のログインに案内され、ログインすると［使い方を開く］が出ます。
