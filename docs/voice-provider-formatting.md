# 音声整形の接続先切り替えと実測

更新日: 2026-10-20 / ブランチ: refactor/agent-connection / 未マージ

## 動作

- 録音開始時の認証方式を保持し、Claude Codeなら従来のHaiku CLI、CodexならChatGPT認証のCodex、APIモードなら設定済みAnthropicキーのHaikuを使う。
- Codex経路ではClaude実行ファイル・Claude認証を参照しない。他プロバイダーへの自動フォールバックはしない。
- マイクの開始前にはAI接続・モデル一覧取得を行わない。認識結果が得られた後に整形する。
- 共通プロンプト・結果検証・60秒上限・キャンセル・原文救済を維持。質問の箇条書き、明示的な禁止の保存を補強した。
- 相談とは独立した一時セッションで処理する。音声整形のモデルは相談モデルに連動させず、Codexの利用可能一覧にgpt-5.6-lunaがあればlowを使用。利用不可なら同じCodexの既定モデル／対応effortにする。
- CodexRpcの起動・認証・モデル一覧処理を再利用。音声専用の接続処理はagents/codex-text.ts、振り分けはvoice-formatter.ts。大きなエージェント抽象化は追加しない。
- Codexは読み取り専用・承認不可・ephemeral。プロセス内だけでスキル指示・プロジェクト指示・hooks・外部ツール等を無効化し、設定済みMCPサーバーもスレッド設定で無効化。利用者の設定ファイル・認証情報は変更・コピーしない。想定外のツール要求が発生した場合は停止する。
- CLI 0.153.4で実動作確認。将来のCLI仕様変更時は音声専用設定の再検証が必要。
- ログにはプロバイダー・モデル・準備／生成時間・トークン数・成功可否のみを記録。認識原文・整形文・認証情報は記録しない。
- 利用上限エラーは日本語で案内し、原文を残す。Windowsの音声入力は引き続き未対応。

## 実測方法と限界

このMacのCodex CLIと既存のChatGPTログインを使用。認識済みの日本語テキストを直接渡し、接続開始から整形完了までを測定した。マイク準備・発話時間・音声認識確定時間は含まない。各例1回の小規模確認であり、平均的な品質や速度の保証ではない。録音UIを通した実際の発話は利用者による確認待ち。

最終プロンプトでgpt-5.6-luna/lowを10例確認。中央値3.14秒、範囲2.42〜5.19秒。入力約2,800トークン、出力19〜44トークン。初回の接続準備は1.61秒、以降の準備は0.14〜0.32秒だった。

比較用gpt-5.6-sol/lowは、プロンプト補強前の同じ3例で平均3.89秒、Lunaは平均3.01秒だった。補強後のSol比較は429エラーになり停止。最終プロンプトでの同条件比較は未完了なので、速度差を断定しない。

初回に「複数の質問が箇条書きにならない」「削除しないという明示的な禁止が省かれる」例を確認し、共通プロンプトを補強。下表は補強後の実結果。発話内の質問に回答したり、指示を実行したりしなかった。

## 最終プロンプトの結果

### 訂正（4.44秒）

入力: えーと、私が言いたいのは、その、明日の会議は火曜日に変更、あ、違った、水曜日の午後2時です

出力:

明日の会議を水曜日の午後2時に変更します。

### 箇条書き（3.14秒）

入力: うん、ええと、お願いしたいことは、履歴を残してほしい、あとマイクは一度選んだら覚えておいてほしい、それと音量も見えるようにしてほしい

出力:

- 履歴を残してほしい。
- マイクは一度選んだら覚えておいてほしい。
- 音量も見えるようにしてほしい。

### 短文（3.01秒）

入力: うーん、いや、だからまあ、マイクは一度選んだら覚えておいてほしいです

出力:

マイクは一度選んだら覚えておいてほしいです。

### 否定・条件（5.19秒）

入力: いや、それは違います。えっと、雨だから延期するんじゃなくて、担当者が来られないから延期したいです

出力:

それは違います。雨だから延期するのではなく、担当者が来られないので延期したいです。

### 引用（3.15秒）

入力: ええと、彼は「うん」と答えた、と記録しておいてください

出力:

彼は「うん」と答えた、と記録しておいてください。

### 質問の整形（2.91秒）

入力: うん、ええと、SQLiteに移行しなくてもできるんですか、あとWindowsでも使えますか

- Windowsでも使えますか？

### 数値・固有名詞（2.80秒）

## 検証範囲

自動テスト45件、型チェック、対象コードのLint、ビルドが成功。自動テストで、Codex/API経路からClaudeを呼ばないこと、開始時設定の保持、失敗時のフォールバック禁止、原文保持、キャンセル、独立セッション、MCP無効化、利用上限エラーを確認。実測はCodexのみ。APIモードの実アカウント通信と、更新後のClaudeの実アカウント通信は未実施（既存CLIテストと振り分けテストで確認）。

## 試し方

開発版ACBの相談設定でCodexを選んで保存し、マイクボタンまたは設定済みショートカットで録音を開始・停止する。本文の整形と入力欄への挿入、チャット切り替え時の挙動を確認する。試用確認後にマージする。
