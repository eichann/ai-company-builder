# 相談履歴の永続化・手動削除（第1段階）

ブランチ: `fix/chat-history-persistence`

## 保存方針

既存の Electron `userData/chat-history/<companyId>.json` を継続利用する。各PC・OSユーザーのローカル保存であり、サーバーDBへの移行や利用者間の履歴共有は行わない。同じOSユーザー内でのACBログインアカウント別の分離は、今回追加していない。

30日経過・未ピン留め100件超による自動削除を廃止する。閉じたタブの相談も履歴に残す。今回の削除対象はACBの履歴と下書きで、Claude Code自身が管理するセッションファイルではない。

## 実装

- 起動時から相談IDを確定し、復元中にタブの保存IDをnullで上書きしない。
- 同じ相談を開く操作は既存タブへ移動する。保存済みの重複タブも復元時にまとめる。
- ユーザー発言は送信前に保存する。回答生成中も1秒間隔で変更を保存し、タブ終了・画面再読込・アプリ終了直前に同期保存する。未送信の下書きも含む。
- 終了時の保存エラーでは終了を止め、画面にエラーを表示する。
- 書き込みはElectronのメインプロセスに集約。一時ファイルへの書き込みとfsync後のrenameで置換する。複数プロセスの同時起動も抑止する。
- revisionと書き手ごとの連番で古い保存を拒否する。名前変更・ピン留め・ClaudeセッションIDの更新は本文から分離し、古い本文の上書きを防ぐ。
- 破損ファイルを空の履歴として扱わず、読み書きを停止してエラーを表示する。直前の正常な内容を `.json.bak` に残す。
- 削除は確認画面を経由。削除IDを記録して遅延保存による復活を拒否し、該当タブを閉じる。通常の復旧用バックアップからも削除した本文を除く。
- 以前に別IDで作成された、内容が似た相談の自動統合はしない。別の相談を誤って消さないため、必要に応じて手動削除する。

型検査とViteビルドは成功。新規ファイルのlintは成功。既存main/preloadのlintエラー6件は変更前と同数で、今回の変更による増加はない。既存の本番相当データ53件は読み取りのみで検証した。

さらに隔離したElectron環境で、実際のChatPanel・preload・履歴ストアを使い、以下を確認した。AI応答と認証情報はテスト用の代替を使用し、実際の相談やAIへの送信はしていない。

1. 入力直後にウィンドウを閉じても下書きが保存・復元される。
2. 発言・回答が重複せず保存される。
3. 名前変更・ピン留め・同じ履歴を繰り返し開く操作。
4. 複数タブの状態と下書きがElectron終了・再起動後に復元される。
5. 手動削除のキャンセル・確定・削除後の再読込。
6. 保存失敗時に終了を止め、下書きとエラーが画面に残る。
7. タブを閉じても、その下書きが履歴に残る。
